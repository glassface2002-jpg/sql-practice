# SQL Practice Lab

**Learn SQL in your browser: 32 interactive lessons with auto-graded practice, from SELECT to window functions. No install needed.**

### ▶ [Open SQL Practice Lab](https://glassface2002-jpg.github.io/sql-practice/)

An interactive SQL course that runs entirely in your browser. There are 32 lessons, from your first `SELECT` to window functions. Each one has a short explanation, a live SQLite database and auto-graded practice tasks.

## What's covered

**Core lessons:** SELECT, filtering with WHERE, sorting and limits, INNER and OUTER joins, NULLs, expressions, aggregates, GROUP BY and HAVING, the order a query runs in, INSERT, UPDATE, DELETE, CREATE TABLE, ALTER TABLE and DROP TABLE, plus two review lessons.

**Further topics:** subqueries; UNION, INTERSECT and EXCEPT; primary and foreign keys; dates and times; views; CASE; string functions; indexes; transactions; common table expressions, including recursive ones; window functions; and a set of final challenges.

## How to use it

- **Online:** open the GitHub Pages site for this repository.
- **Offline:** download or copy the folder and double-click `index.html`. It needs no internet connection and no install.

Write each query in the editor and press **Run query** (or <kbd>Ctrl</kbd> + <kbd>Enter</kbd>). A task ticks off when your result matches. If you're stuck, the first click shows the keywords you'll need and the second shows the full solution.

Progress is saved in your browser. To continue on another computer, use **Copy my progress code** at the bottom of any lesson and paste the code into **Load progress code** there.
